# I7 — production replay and draft reconciliation

`cmd/kogen-xspec` exposes production-backed adapters for `intent`, `approve`,
`queue`, `status`, `stream`, and `session`. `recovery` and `rebase` are named
release G slices, but the binary exits with an explicit unavailable-adapter
error for them. No replay policy model substitutes for their missing
production event adapters.

The four D observations (`gate`, `orchestration`, `accounts`, and
`setup-cache`) remain in the diagnostic package. They are classified as D and
their comparisons always set `counts_toward_g` to false. No D fixture is
counted as a G conformance result.

`tools/replay.py` accepts only a clean Go checkout and a clean authoritative
spec checkout with a committed `kogen-shared-v1.3-cohort/v1` manifest. The
manifest must bind the v1.3-draft migration, each of the eight G slice trees,
their hand-scenario/golden counts, the shared harness digest, and the four D
slices with `migration: observational` and `counts_toward_g: false`. The CLI
and private xspec binary must both be clean Go builds from the same Go revision.
The runner copies the prototype and slices into an isolated output directory,
checks hand goldens, runs `spec`, generates 500 traces of 25 steps for seeds
17, 23, and 41, then conforms each complete observation against the private
binary. D slices are written to the report in a separate, non-counted section.

The current spec checkout has no committed coherent migrated cohort manifest
and contains local changes. The current Go production adapters for recovery
and rebase are also unavailable. The replay tool therefore refuses behavior
acceptance until the shared cohort and production event adapters are ready.
See [I7 evidence](I7-production-replay-and-draft-reconciliation.evidence.md)
for exact revisions, commands, historical results, and closure gates.

The required frozen v1.2 command resolved all 242 selected cases across 576
instances: 61 cases passed and 181 failed, with no runner errors, skips, or
unimplemented cases. Its complete results are retained outside the source tree.
These are v1.2 case outcomes; they do not establish any R(slice) draft pass.
