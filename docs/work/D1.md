# D1 — Observational audit regression

This package adds component regressions for the v1.3-draft rule that Build audit is advisory only. The new audit test checks `over_strict` and `contradicts` receipts and repair feedback. The selector test sends those replies through the real audit and gate APIs, keeps failed A2 in the approved count, and checks that audit timing and reversed parallel completion order leave ranking and winner unchanged.

The config refusal is covered by `internal/project/project_test.go` (`build.auditor_demotion: true` returns `build.auditor_demotion has no admitted calibration`). Existing audit tests cover malformed and duplicate replies; existing audit and selection tests cover observational journal/report fields.

**Gate status: component only.** The frozen v1.2 ladder cases stop at the unwired public approval route, before reaching audit behavior. The planned D-AUD replacements are not frozen v1.2 cases; behavior acceptance and I4 closure await the shared v1.3 suite and integrated Build/ladder rerun. See [D1 evidence](D1-observational-audit-regression.evidence.md) for commands, exact results, conflicts, and closure gaps.
