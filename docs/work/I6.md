# I6 — Optional and OS wiring

## Component work

`internal/app/optional_wiring.go` adapts the existing recipe-stage, edge-check,
witness, checkpoint, and sandbox components to the app boundary. Recipe role
resolution and checkpoint bytes remain owned by their component packages.
Enabled edge checks are a required landing conjunct, and witness mode remains
opt-in. Build sandbox wiring uses the Seatbelt runner on macOS and the pinned
bubblewrap probe/prepare path on Linux; unavailable confinement requires
before/after integrity snapshots around child execution.

The tests cover all 13 recipe fixtures, edge-check conjunctions, checkpoint
threshold and byte/epoch preservation, witness defaults, sandbox unavailable
and disabled modes, and an actual supervised child write following the host
probe. The focused tests and macOS adversarial safety matrix passed.

## Integration boundary

This worktree owns the optional wiring adapter, its tests, and this note. The
public Build route still does not call `ConfigureSingleBuild` or
`ProbeBuildSandbox`, and the public Shape command still reaches its integration
stub. Consequently, neither the public Linux confinement path nor witness
behavior is accepted by this component result. The exact frozen v1.2 command
and its failures are recorded in `I6-os-optional-safety-parity.evidence.md`.

The gate is component-only. Linux adversarial/custody execution, public route
integration, actual Rails/ExUnit behavior, shared frozen v1.3 fixtures, and the
coherent Quint `R(slice)` run remain closure gates.
