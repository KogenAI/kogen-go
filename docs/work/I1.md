# I1 public foundation

`cmd/kogen` enters through `internal/app.CLI`, which runs the fixed argv parser,
renders the embedded help and usage pages, and dispatches version, status,
Intent approval, and Intent removal.

Project routes use the resolver and supervised Git ports. Approval composes the
exact-byte Intent parser, lint and hash logic with protected-manifest checks,
exact-base preparation, the persistent setup/baseline cache, immutable approval
publication, and source re-reads before ref compare-and-swap. Intent removal
uses the rooted filesystem and path-limited Git commit implementation.

Status reads current Intent files and approval refs, derives draft/queued/landed
states with `internal/status/derive`, and uses the shared text and JSON renderers.
This is the foundation status observer: Build records, crash recovery, live
queue ownership, agents, and watch polling are closed with I3. Queue execution
and provider routes remain with I3 and I2 respectively; Shape execution remains
with I5. Those route handlers return an explicit controller error until their
integration round.

`foundation_test.go` exercises exact help/parser behavior, version output,
symlinked project selection, raw-byte approval cards and hashes, approval-ref
publication, synthetic queue status, and draft removal through a real local
checkout and bare Git origin.
